COMPOSANTS TIERS
Le programme embarque PyMuPDF (licence AGPL v3, la même), ainsi que
Python, python-docx, openpyxl et lxml (licences libres permissives).
Le dossier Tesseract contient Tesseract OCR (licence Apache 2.0, jointe)
et les bibliothèques qui l'accompagnent. La liste complète, avec les
versions et les licences, est dans COMPOSANTS_TIERS.txt.

EMPREINTES
EMPREINTES_SHA256.txt donne l'empreinte de chaque fichier du paquet,
pour repérer un fichier abîmé ou modifié. Pour vérifier que le zip reçu
est bien l'original, comparez son empreinte à celle publiée avec le
lien de téléchargement.
